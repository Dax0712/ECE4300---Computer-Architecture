# Architecture Study

This section is for broader computer-architecture material that accompanied the Verilog pipeline work.

Topics include:

- Instruction Set Architecture (ISA)
- MIPS instruction formats and datapath behavior
- RISC-V as a modern open and extensible ISA
- Pipeline hazards and instruction scheduling
- Forwarding and Tomasulo's algorithm as studied techniques
- Hardware-security topics such as Spectre, cache timing, and RowHammer
- Proposed FPGA-based hardware-security experiments

The Verilog processor elsewhere in this repository is MIPS-style; the RISC-V material belongs here as architecture study rather than being presented as the implemented processor.
